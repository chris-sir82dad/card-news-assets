# card-news-assets

카드뉴스 이미지 호스팅 저장소입니다. **내용물은 전부 기계 생성물이고, 사람이 직접 편집하지 않습니다.**

## 왜 이 저장소가 따로 있나

Instagram 콘텐츠 발행 API는 이미지를 바이너리로 업로드할 수 없고, **발행 시점에 공개 URL로 접근 가능한 이미지**만 받습니다. 그래서 발행 직전에 JPEG를 여기에 커밋하고 `raw.githubusercontent.com` URL을 API에 넘깁니다. 이 저장소가 public인 이유가 그것뿐입니다.

생성기(코드·원고·설정)는 별도의 비공개 저장소에 있습니다.

## 구조

```
cards/<발행ID>/01.jpg … NN.jpg
```

- 전부 **1080×1350 (4:5) JPEG**입니다. Instagram이 캐러셀의 모든 장을 첫 장의 비율로 크롭하기 때문에 크기가 고정입니다.
- 파일명 순서가 캐러셀 순서입니다.

## URL은 커밋 SHA로 고정됩니다

```
https://raw.githubusercontent.com/<owner>/card-news-assets/<커밋SHA>/cards/<발행ID>/01.jpg
```

브랜치명 대신 커밋 SHA를 씁니다. 브랜치 URL은 CDN 캐시 때문에 방금 푸시한 파일에 404가 날 수 있고, SHA URL은 불변이라 그 문제가 없습니다.

발행이 끝나면 Instagram이 이미지를 자기 CDN으로 복사하므로, 여기 있는 파일은 **발행 순간에만 필요**합니다. 이후에 파일이 사라져도 이미 게시된 글은 깨지지 않습니다.

## 커밋 이력

커밋은 `cardnews-bot`이 자동으로 만듭니다. 사람 이름의 커밋이 있으면 저장소 설정이나 README 수정입니다.

## 라이선스

미정입니다. 이미지에 대한 권리를 별도로 부여하지 않으며, 카드에 인용된 기사 제목과 출처는 각 언론사에 귀속됩니다.
